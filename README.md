깃허브 페이지로 배포하는방법

명령어

1.  cd "내 컴퓨터의 프로젝트 경로"                                                                                                                             
2.  git init                                                                                                                                                         
3.  git add .
4.  git commit -m "커밋 메시지"                                                                                                                                  
5.  git branch -M main
6.  git remote add origin 배포주소/레포이름.git
7.  git push -u origin main
